# /ws/diarize (speaker diarization). Heavy, optional at import time (see
# app/diarization.py) -- the rest of the backend works without them, but
# diarization will report itself unavailable until these are installed.
#
# IMPORTANT: requires Python <=3.12. diart pins numpy<2.0, and numpy stopped
# publishing prebuilt Windows/most-platform wheels for the 1.x line before
# Python 3.13 existed, so installing this on 3.13 tries to compile numpy
# from source and fails without a C compiler. Use `py -3.12 -m venv .venv`.
#
# torch/torchaudio/torchvision are pinned (rather than left open per
# diart's own >=2.2 constraint) because newer torchaudio releases removed
# `torchaudio.AudioMetaData`, which pyannote.audio 3.4.0 still imports --
# pip's resolver will happily install an incompatible newer torch otherwise.
diart>=0.9,<1.0
torch==2.2.2
torchaudio==2.2.2
torchvision==0.17.2

# pyannote.core's notebook module imports matplotlib.cm.get_cmap, removed in
# matplotlib 3.9.
matplotlib<3.9

# pyannote.audio 3.4.0 still calls hf_hub_download(..., use_auth_token=...),
# a kwarg huggingface_hub's 1.x line removed outright (not just deprecated).
# NOTE: do not `pip install transformers` in this environment -- its latest
# releases require huggingface_hub>=1.5, directly conflicting with this pin.
# It isn't a real dependency of anything here; see the docstring on
# _patch_speechbrain_windows_lazy_import_bug() in app/diarization.py for why
# it can seem like one.
huggingface_hub<1.0

# supposed to prevent pytorch_lightning's inspect.stack()-based JIT check
# from incidentally trying to import speechbrain's optional integrations
# (k2, transformers, ...), but the guard's path check is Unix-only and never
# fires on Windows. app/diarization.py monkeypatches this at runtime
# (_patch_speechbrain_windows_lazy_import_bug), so no extra packages or
# version pin are needed here for this specific issue -- noted so a future
# `pip install k2` / `pip install transformers` "fix" attempt (which does NOT
# work, see above) isn't tried again.
