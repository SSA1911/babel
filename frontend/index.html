Settings

Leave blank to use this page's own host. Only needed if the frontend and backend are served from different addresses.

Spoken languages

Select every language you expect to hear. If every language you pick is tagged "auto", Babel switches between them automatically as speakers change languages (Deepgram's native code-switching — reliable because it listens for all of them at once, not by guessing from already-transcribed text). If any pick isn't tagged "auto", automatic switching isn't reliable for that combination — you'll get a manual language-picker in the transcript view instead.

Speaker separation

Labels who's speaking. Needs the backend's diarization setup (HUGGINGFACE_TOKEN + diart) — leave off if you haven't configured that yet.
