Settings

Leave blank to use this page's own host. Only needed if the frontend and backend are served from different addresses.

Spoken languages

Select every language you expect to hear — all of them are detected automatically as people switch, with no toggling. Languages tagged shared are transcribed together by one stream and can be mixed freely within a single sentence. Each language without that tag needs its own parallel stream, which is billed separately and detects language per sentence rather than per word.

Reconstruct mixed speech

When two streams disagree closely — the signature of a sentence mixing two languages — send both transcripts to the translator so it can work out what was actually said. Only engages on genuine near-ties.

Show latency

Print time-to-first-word and total translation time under each bubble.
